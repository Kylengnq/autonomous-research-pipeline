# Design notes

`skill-specs.md` is the per-skill writing spec: for each skill, what it must do,
which gates it owns, and the failure it exists to prevent. Read it before adding
a skill or changing one substantially.

Nothing here runs. The skills that execute are in `../.claude/skills/`, and that
is the only place to read what a rule currently is.

This document was written from real runs whose specifics have been removed.
Where it cites a measurement without naming the run that produced it, that is
deliberate.
